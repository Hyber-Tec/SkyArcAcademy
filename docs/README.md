# The docs

Every doc, and where it lives. Start with [`CLAUDE.md`](../CLAUDE.md) and the brief
([`SKYARC_PROJECT_BRIEF.md`](../SKYARC_PROJECT_BRIEF.md)); CLAUDE.md says which to read next. People's names, money and
each meeting's own notes are in the private notes, `internal/` (CLAUDE.md, "Local files").

## At the top: the living docs

| Doc | What |
|---|---|
| [`DECISIONS.md`](DECISIONS.md) | The owner's answers, by date. They win over the brief and the review. |
| [`QUESTIONS.md`](QUESTIONS.md) | What's still open, with the defaults used meanwhile. |
| [`TODO.md`](TODO.md) | The owner's to-do: a short checklist, what's done at the bottom with ✅ and the date. |
| [`TODO-notes.md`](TODO-notes.md) | The to-do's details, under the same titles. |
| [`DEPLOY.md`](DEPLOY.md) | How `main` reaches production, and the academy's domain. |

## In folders

| Folder | What |
